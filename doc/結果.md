# 實驗結果總覽

模型：Llama 3.1 8B-Instruct
評測資料集：LongBench v1
樣本數：narrativeqa=200, qasper=200, multifieldqa_en=150

## 比較框架

| 方法 | 說明 |
|------|------|
| **FullKV** | 不壓縮，作為上限基準 |
| **FINCH (orig)** | 原始方法：sum over all heads，split_size=512 |
| **FINCH (per_head_vote)** | 改進方法：GQA-aware per-head vote，split_size=512 |

## narrativeqa

target_token=9137，context_max_length=128000，200 samples

| 方法 | F1 | E2E Latency (ms) | Peak Memory (MB) |
|------|----|-----------------|-----------------|
| FullKV | 26.53 | 10,327 | 40,198 |
| FINCH (orig) | 12.62 | 18,832 | 21,136 |
